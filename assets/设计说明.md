# 原创扩展图标设计

## 构图与用途

图标以简化的代码编辑器窗口表达 AdwCode 的用途。暖白色窗口框架、纯蓝色活动
文件页签、窄侧栏和四行语法色块形成主要识别结构。中间两行缩进，首行分段，
使色块呈现代码结构。具体适用 Visual Studio Code 的信息由扩展名称和说明提供。

扩展清单与 README 使用同一份 `adwcode.png`。图标采用通用几何，不使用第三方
徽标；本设计与工作台的产品图标字体、映射保持独立。

## 视觉约定

- 接近方形的圆角窗口，保留足够的透明画布边距。
- 蓝色页签保持纯色，不添加文档标记、文字或其他符号。
- 深色代码区包含窄文件侧栏，侧栏仅保留两条灰色文件标记。
- 四行代码使用薄荷绿、蓝色、珊瑚色及少量奶油色，保持明确缩进和充足留白。
- 使用哑光表面、上方光照与较暗的浅底部侧面，控制倒角和厚度。
- 不增加配色卡、状态栏、细小文字或主轮廓之外的投影。

## 制作与许可

2026-10-06 使用内置 imagegen 按文字描述生成原创编辑器图像，再编辑自有图像以
简化界面并移除页签中的图标。未向生成工具提供第三方徽标或图像。最终采用的
1254 × 1254 透明 PNG 保持生成后的像素和构图，不再调整比例。

生成描述：原创 GNOME 风格代码编辑器图标，暖白色圆角窗口、纯蓝色文件页签、
窄侧栏及四行带缩进的彩色代码。透明背景，正面视角，哑光表面和浅立体厚度。
保持简洁，避免文字、徽标、前景配件及细小界面元素。

图像生成不保证逐像素复现；随附 PNG 是固定最终效果的位图原件，没有对应的
矢量源文件。来源、许可及 SHA-256 见 [来源记录](来源.json)。本项目对有权
许可的图标内容采用 `CC-BY-SA-4.0+ OR AGPL-3.0-or-later` 双重许可，使用者可
任选其一；署名与两种许可全文的路径见 [图标许可证](LICENSE)。

## 验证范围

更新图标时核对 PNG 尺寸、透明通道和来源哈希，并在浅色与深色背景下检查
128、64、32、16 像素的展示。16 像素时细小分段可能合并，主要保留窗口、页签
与代码色块的轮廓。完成项目完整检查与打包后，核对清单和 VSIX 图标资源。
不要以静态校验代替当前扩展列表的视觉验证，也不要自动重载工作窗口。
