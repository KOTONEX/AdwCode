# 中文接口迁移

本次对项目自有接口彻底更名，不保留英文命令、设置键、脚本参数和文件名的兼容入口。
VS Code、Git、npm、TypeScript、Python 等规定的 API、配置字段、标准文件名与
第三方名称保留原文。例如 `activate`、`deactivate`、`package.json`、`README.md`、
`AGENTS.md`、`LICENSE`、`tsconfig.json` 及 VS Code 颜色键不能随意翻译。

## 设置与命令

| 旧设置键 | 新设置键 |
| --- | --- |
| `adwcode.uiFontFamily` | `adwcode.界面字体` |

`adwcode.自动重载`（旧键 `adwcode.autoReload`）已随功能移除：扩展不再监视文件、
不再自动重载窗口，设置面板中不再提供该项，残留的设置值不会生效。

| 旧命令标识 | 新命令标识 |
| --- | --- |
| `adwcode.appearanceStatus` | `adwcode.查看外观安装状态` |
| `adwcode.closeOnlyControls` | `adwcode.安装仅关闭窗口控件` |
| `adwcode.installGnomeLook` | `adwcode.安装GNOME外观` |
| `adwcode.applyRecommendedSettings` | `adwcode.应用推荐设置` |
| `adwcode.revertRecommendedSettings` | `adwcode.恢复推荐设置` |

`adwcode.应用推荐设置` 与 `adwcode.恢复推荐设置` 已随功能移除：推荐值改由
`package.json` 的 `configurationDefaults` 声明，只在用户或工作区未显式设置时
生效，不再写入用户设置。

升级只需直接安装新 VSIX，不要求手动迁移设置或快捷键、禁用加载器或清理文件。
旧键与旧命令不再生效，未显式设置的项采用清单默认值。
上表用于查阅新接口名称，自定义快捷键或外部脚本如需继续调用相关功能，可按需更新。

## 开发入口

| 用途 | 新入口 |
| --- | --- |
| 生成主题 | `meson compile -C builddir 主题` |
| 校验 | `meson compile -C builddir 校验` |
| 静态检查 | `meson compile -C builddir 静态检查` |
| 类型检查 | `meson compile -C builddir 类型检查` |
| 格式化 | `meson compile -C builddir 格式化` |
| 打包 | `meson compile -C builddir 打包` |
| 变更日志 | `meson compile -C builddir 变更日志` |
| 发布说明 | `meson compile -C builddir 发布说明` |
| 性能基准 | `meson compile -C builddir 性能基准` |

完整检查仍使用 Meson 的标准命令 `meson test -C builddir --print-errorlogs`。
npm 的标准 `test` 生命周期也保留；自有脚本名称已使用中文，如 `npm run 构建`。

Python 模块与自有函数、类型使用中文，如 `from 调色板 import 调色板对象`、
`from 生成主题 import 生成主题对象`。原有导入语句、函数名和模拟测试引用均须更新。
具体职责与新路径见 [架构说明](03-架构与实现状态.md)。

```sh
python3.14t 源码/生成主题.py --校验
python3.14t 源码/生成变更日志.py 发布说明 --标签 "v<版本>"
python3.14t 源码/打包扩展.py --变更日志 /路径/CHANGELOG.md
```

VS Code 的 `dark` / `light` 类型及协议字段属于外部接口，
保留其标准标识。生成的主题文件名已使用中文并保留 `adwcode-` 前缀；颜色内容
不因名称迁移而修改。VS Code 读取清单中的新路径，第三方原始文件名保持不变。

## 外观与安装

自有样式与脚本改为 `GNOME外观.css`、`GNOME字体.css`、`仅关闭窗口控件.css`、
`窗口状态.js`；扩展入口改为 `扩展/扩展.js`。执行“AdwCode: 安装 GNOME 外观（CSS）”
写入新副本与新加载引用，并自动清理本扩展源码目录及 `~/.config/adwcode` 中的旧版引用；
保留其他用户加载项。此清理不提供旧版接口兼容，也不删除旧文件或重载窗口。

## 直接安装新 VSIX

直接安装新 VSIX 即可升级，无需卸载旧版，也不要求额外的配置清理步骤：

```sh
code --install-extension "AdwCode-<版本>.vsix"
```

将 `<版本>` 替换为下载附件的实际版本号，或直接使用附件文件名。

扩展标识仍为 `KOTONEX.AdwCode`，VS Code 会将此安装作为现有扩展的更新。
如需重新安装相同版本，可追加 `--force`；这不是普通升级的必需参数。
官方行为见 [VS Code 命令行说明](https://code.visualstudio.com/docs/configure/command-line)。

GNOME 外观安装是可选功能，沿用其使用说明；默认设置随安装生效，
不作为升级的额外必需步骤。
安装不会自动迁移用户自定义的旧键、快捷键或外部脚本，也不会重新注入现有加载器补丁。
旧键与旧命令不再生效，新设置使用默认值。

自动化检查不执行安装或窗口重载；静态检查与离线测试不代表当前窗口已采用新版本。

## 自有目录

源码、测试、主题、资产、扩展、附加外观、产品图标、文档、类型声明和基准目录均采用简体中文。
调用路径以仓库当前清单为准；`.github`、`.vscode`、`LICENSES` 和工具生成的缓存、构建目录
保留工具约定名称。VSIX 内部的标准 `extension/` 根目录保持不变。
