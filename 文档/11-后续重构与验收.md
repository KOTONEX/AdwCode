各方向独立提交和发布，修复已发布行为时使用修订号。保持 rust 候选发布，main 不变。

| 版本 | 方向 | 验收 |
| --- | --- | --- |
| 4.3.0 | 扩展模块化 | 原有状态、引用和文件/配置回滚测试；完整检查；隔离安装 |
| 4.4.0 | 测试接口与独立宿主 | 共用显式模块接口；独立 Extension Development Host 中命令和配置作用域 |

## 4.3.0 扩展模块化

入口只装配本机依赖并注册五个命令。组件、字体、引用、状态、事务使用独立工厂；
每次创建服务均拥有自己的字体缓存、输出通道和串行队列。文件和配置的恢复仍由
事务模块整体协调。无构建步骤、无运行时依赖的 JS 发布方式保持。

语法检查递归覆盖扩展模块，TypeScript 检查覆盖 `扩展/**/*.js`。离线测试使用
显式服务接口，不再访问 VM 内的私有变量；宿主夹具的共用整理在下一阶段进行。
基准的创建场景改名为“外观服务创建（模块实例）”，测量模块工厂，不能与旧 VM
加载场景直接比较；其余场景仍调用真实状态逻辑和命令注册实现，报告结构保持。

## 4.4.0 测试接口与独立宿主

`测试/扩展宿主.cjs` 提供服务工厂和真实 CommonJS 入口加载器，离线回归与基准共用。
VM 只隔离入口依赖，测试不再访问私有作用域。补齐真实入口五命令注册/释放、取消无写入
和实例状态隔离。基准加载场景包含入口加载，名称改为“扩展加载（显式宿主接口）”。

`cargo run --quiet -- 宿主测试` 启动独立用户数据、扩展目录及临时工作区；测试真实 API
的命令注册、Global/Workspace 优先级和状态命令，恢复设置后关闭进程组并清理。
不运行安装、加载器或重载命令；报告为 `builddir/宿主测试.json`。独立宿主不代表外观视觉验收。
CI 通过官方测试工具下载稳定编辑器并在 Xvfb 下执行，此工具不成为扩展运行依赖。

4.4.0 发布前 CI 发现下载版 Electron 的沙箱辅助程序没有 root/setuid 安装权限；
独立测试新增明确的 `--禁用沙箱` 参数用于 CI，本地默认行为保持沙箱启用。

## 4.5.0 SVG/字体管线拆分

`源码/库/图标生成/mod.rs` 保留来源校验与两个生成入口；`几何.rs` 负责路径、布尔运算和字重，
`矢量解析.rs` 负责 XML/SVG 与绘制策略，`字体封装.rs` 写入字体表，`预览.rs` 导出 SVG，
`测试.rs` 保留全部图标回归。跨模块接口只对本管线可见；算法、常量、容差和遍历顺序保持。
以 4.4.0 资产为基线，重新生成全部字体及 SVG 预览后逐字节核对，完整检查与隔离安装另行通过。

## 4.6.0 基准公共工具

`运行工具.rs` 提供程序查找、受管进程组和显式过滤策略的目录复制；性能基准、工作台基准
与独立宿主测试共用，避免宿主测试依赖工作台基准实现。性能基准仍过滤 Python 缓存，
工作台复制保留全部内容；来源与目标拒绝符号链接，被过滤条目也先校验，IO 错误传播。
进程清理保持 TERM、最多一秒等待、KILL 后回收，主进程退出仍清理后代。
新增过滤差异、缺失来源/文件目标、来源/目标/被过滤符号链接回归，保留真实错误返回清理测试。

## 4.7.0 发布执行器

外部发布工具统一进入 `发布执行.rs`，独立进程组、无交互输入，stdout/stderr 写入临时文件
避免管道阻塞。GitHub 查询 60 秒、附件和 Release 操作 180 秒、市场发布 600 秒超时；
正常退出、错误或超时都清理本次进程组。stdout 超过 8 MiB 停止发布；诊断读取有上限。
错误携带具体阶段、退出码或超时，去除终端控制序列并遮蔽四种发布令牌，诊断截短后输出。
仅明确 HTTP 404 允许创建 Release，401/403/429/服务端错误仍停止；附件一致性与市场权限不变。
真实子进程测试覆盖退出码、脱敏、较大 stderr 不阻塞及忽略 TERM 后代的超时清理。
已成功的远端操作无法回滚，重新运行仍使用相同附件核验；没有替换公开附件的操作。

## 4.8.0 颜色映射规则与表达式

按全部方向授权将原先建议暂缓的颜色映射作为最后一项实施。`界面映射/规则.json` 保存
983 条登记/覆盖、注释及终端插入点；Rust 只保留有序收集与受限表达式解释器。
规则编译时嵌入并在进程内只解析一次，不引入外部代码执行、额外运行依赖或 Cargo 依赖。
普通主题的空值省略、原位覆盖、终端16色位置与样式缺失回退语义保持。

规则校验字段、类型、操作、条件、比例范围、色阶级数和嵌套深度；不存在的角色/表面返回错误。
未知操作或字段不会忽略。原有8个金样例通过；另以4.7.0当前实现为独立基线，按实际启用
强调色清单比较明暗、对比度及彩色状态栏组合，8个场景颜色与顺序逐字节相同。
验收记录在 `builddir/4.8.0映射验收.json`；完整检查、主题再生成与隔离打包另行验收。
本方向改善规则维护方式，不承诺性能提升，解释器与格式校验仍需要维护。
