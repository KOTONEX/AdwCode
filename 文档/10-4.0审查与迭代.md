# 4.0 审查与迭代记录

本轮工作在 `rust` 分支完成，不合并或推送 `main`。扩展版本来自 `package.json`。

## 首轮审查

审阅基线为 `d4e1c6c`：326 个受版本控制文件，包含全部 Rust、JavaScript、CSS、类型声明、测试、配置和文档；JSON、XML、SVG 逐文件解析，69 张 PNG 解码及图集视觉检查，五份 TTF 检查表目录及字形数，许可证核对全文。阅读 `rust` 的提交记录及相对主线的 25 个迁移提交，核对新增实现、修改补丁和原 Python 关键语义。生成数据的逐条解析与二进制结构检查不等同于当前窗口外观验收。

确认并修复：

- 有序颜色映射重复键应原位覆盖；无参数命令拒绝尾部参数，帮助补齐命令。
- JSONC 注释不能连接相邻令牌或吞掉未闭合注释；颜色别名循环、非法颜色及未知模式返回错误。
- 主题必需字段及字体路径恢复严格校验，按单个主题报告缺失键；普通主题继续省略对比度边框。
- SVG 闭合曲线不能因零弦长消失；采样点推进、XML 根结构和 TTF 表边界补齐检查。
- 工作台基准所有退出路径清理本次独立进程组；附加脚本纳入语法检查。
- 外观安装遵守 XDG 配置路径并识别旧引用；修正仍指向 Python/Meson 或错误工具参数的当前文档。

回归覆盖重复键、JSONC、颜色循环与边界、主题字段、字形码点、闭环 SVG、破损字体表、异常进程退出和 XDG 迁移。完整 `检查` 通过，既有主题字节对照和字体确定性测试通过。

### 具体实施与依赖

1. I1 先统一加载引用的识别与合并，再提供多选组件和移除引用命令；最后将文件准备、替换、配置更新串成一个队列。配置拒绝或中途写入失败时恢复原副本与原用户配置，并单独报告恢复失败。取消选择不写入；移除操作保留磁盘副本，其他加载项和工作区覆盖保持由用户管理。新增命令注册、最小 API 声明、README 与故障回归一起交付。
2. I2 在生成器之下增加共享文件事务：预检全部目标、同目录暂存新内容与备份、逐项替换、异常逆序恢复。主题与清单同批提交，只清理自有前缀；默认键表及全部字体和预览同批提交。打包采用单次 XML 替换及临时 VSIX，校验身份字段并拒绝符号链接；有 Git 时过滤未跟踪文件。源码、许可证、来源材料和再生成所需测试随包分发，解决 README 链接与源码可获得性问题。
3. I3 在 I2 的写入保护之上加强输入语义：有限比例与透明前景对比度、空下载结果拒绝、SVG 继承和隐藏状态、奇偶填充及字形码点限制。无法直接表达为单色字体的可见特效明确失败；既有信息图标通过来源记录显式采用不透明轮廓。字体及预览一起重生成，校对实际变化，不只依赖哈希或静态选择器。
4. I4 将新增检查纳入 Rust 分支 CI，主题和字体重生成必须与提交一致；发布策略通过真实临时 Git 仓库测试。标签必须匹配清单版本，非主线提交或预发布版本仅创建候选 Release；只有正式标签允许市场发布。候选不设为 latest，远端工作流、附件和 main 引用另做发布验收。

实施顺序依赖 I2 的事务保护支撑 I3，I4 汇总前三项的验证；每项均先完成本地完整检查，再提交及隔离安装。独立 GUI 工作台的视觉和交互验收保留为人工步骤，本轮不重载操作者窗口。

I2 验证：59 个 Rust 测试及完整检查通过。事务在全部准备完成后逐项替换，普通错误触发逆序回滚；断电或强制终止不提供跨文件原子性保证。VSIX 两次构建字节一致，错误不会覆盖旧包。包内附带 Rust 源码、构建清单及离线测试，Git 工作区只纳入受跟踪文件。

I3 验证：颜色运算拒绝非有限和越界比例，对比度合成透明前景；空下载结果保留原键表。SVG 支持呈现继承、隐藏对象及奇偶填充，来源路径拒绝符号链接，字形码点拒绝重复、代理项与 cmap 保留值。信息图标明确采用单色轮廓策略；默认拒绝可见半透明效果。四个奇偶填充字形重生成并同步缩略图，前后图集视觉核对通过；全部字体同步 OS/2 版本 3。六份主题生成内容保持不变。

I4 验证：使用真实隔离 Git 仓库覆盖分支候选、主线正式版、预发布版本、标签版本不一致、缺失主线和手动触发场景。工作流生成全部字体并检查差异，Release 候选状态由同一策略脚本产生；仅正式标签具备市场发布权限，重跑保持固定附件。远端执行结果将在发布阶段核对。

## 第二轮审查与发布

四项完成后复核全部新增代码差异、失败路径、归档内容和发布规则，修复了以下遗漏：

- 多光标前景与背景倒置：依据 VS Code 颜色接口交换四个键，更新六主题和八场景金样例，并校验光标与编辑器背景的对比度。此处有意修正旧输出，不继续沿用旧字节。
- 无加载器时的剪贴板配置应包括其他用户引用；非法加载引用统一报错，状态查询也采用统一错误反馈。
- 仓库定位验证清单身份，防止在其他项目中运行生成器。
- 文件事务规范化路径别名以拒绝重复目标；删除不存在的文件不会在回滚时误报失败。
- 性能基准临时副本、输出和子进程采用自动清理，复制完整 Rust 工具资料，指纹包含源码和字体；目录复制拒绝符号链接，空样本不再越界。
- SVG 组合变换和变换后坐标在轮廓布尔运算之前检查，避免超幅或非有限数据进入算法。

二审完整检查通过，包括 fmt、clippy、Rust 测试、主题及图标校验、Node 语法、TypeScript 和离线扩展/发布测试。字体重生成保持与已提交资产一致，工作流经 actionlint 静态检查通过。五次实际离线性能采样（本机 debug 构建）中位：主题 48.21 ms、校验 26.53 ms、CSS 检查 2186.79 ms、VSIX 325.61 ms；不可直接与旧 release 构建数据比较。

发布版本为 4.0.0，标签采用仓库惯例 `v4.0.0`，仅推送 `rust` 与该标签。发布前须在最终提交隔离副本检查、重生成和安装，核对 4.0.0、确定性 VSIX 及归档内容。发布后核对 Actions、候选 Release、附件和 main 引用；具体远端结果以 GitHub 记录为准，不把本地测试当作远端成功。
