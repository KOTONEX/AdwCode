# 4.0 审查与迭代记录

本轮工作在 `rust` 分支完成，不合并或推送 `main`。扩展版本来自 `package.json`。

## 首轮审查

审阅基线为 `d4e1c6c`：326 个受版本控制文件，包含全部 Rust、JavaScript、CSS、类型声明、测试、配置和文档；JSON、XML、SVG 逐文件解析，69 张 PNG 解码及图集视觉检查，五份 TTF 检查表目录及字形数，许可证核对全文。阅读 `rust` 的提交记录及相对主线的 25 个迁移提交，核对新增实现、修改补丁和原 Python 关键语义。生成数据的逐条解析与二进制结构检查不等同于当前窗口外观验收。

确认并修复：

- 有序颜色映射重复键应原位覆盖；无参数命令拒绝尾部参数，帮助补齐命令。
- JSONC 注释不能连接相邻令牌或吞掉未闭合注释；颜色别名循环、非法颜色及未知模式返回错误。
- 主题必需字段及字体路径恢复严格校验，按单个主题报告缺失键；普通主题继续省略对比度边框。
- SVG 闭合曲线不能因零弦长消失；采样点推进、XML 根结构和 TTF 表边界补齐检查。
- 工作台基准所有退出路径清理本次独立进程组；附加脚本纳入语法检查。
- 外观安装遵守 XDG 配置路径并识别旧引用；修正仍指向 Python/Meson 或错误工具参数的当前文档。

回归覆盖重复键、JSONC、颜色循环与边界、主题字段、字形码点、闭环 SVG、破损字体表、异常进程退出和 XDG 迁移。完整 `检查` 通过，既有主题字节对照和字体确定性测试通过。
