## 文档维护

- 使用文档说明当前用户行为；开发文档说明当前流程；历史目录保留版本事实。
- 工具链政策集中在 AGENTS.md，提交格式集中在 CONTRIBUTING.md，第三方登记集中在许可证文档。
- 行为变更更新对应主文档，其余入口使用链接；不要在首页追加整段迭代报告。
- 移动文档时更新 Markdown、图片、章节锚点和资产链接；当前文档的路径与命令须能在当前树中核对。
- 保留历史数字与方法限制；新结论须有当次环境、提交与验收证据。自动变更日志记录版本变化，不手写重复版本日志。
