# 第三方许可证与引用说明

本项目自有代码以 **AGPL-3.0-or-later** 发布（全文见 [LICENSE](../LICENSE)）。
第三方数据与艺术资产保留各自许可证。本文登记来源、许可及分发边界。

## 1. 随附的数据与资产

### 1.1 GtkSourceView（样式方案）— LGPL-2.1-or-later

- 上游：<https://gitlab.gnome.org/GNOME/gtksourceview>（许可证：LGPL-2.1-or-later）
- 关系：`src/gtksourceview_xml/` 随附其 `Adwaita` / `Adwaita-dark` 样式方案，
  由 `src/tokens.py` 生成 GNOME Builder 风格的语法高亮。
- 边界：只使用样式定义文件，不修改 GtkSourceView 库本身；LGPL-2.1-or-later 与
  AGPL-3.0-or-later 兼容。

### 1.2 VS Code 默认主题数据 — MIT

- 上游：<https://github.com/microsoft/vscode>（许可证：MIT），具体为
  `extensions/theme-defaults/themes/`。
- 关系：`src/vscode_defaults/dark.json` / `light.json` 是内置「2026 Dark」/
  「2026 Light」主题解析后的 `tokenColors`，供「默认语法高亮」变体使用；
  `builtin_keys.json` 与 `registry_keys.json` 是内置主题颜色键并集与官方
  「Theme Color」参考中的颜色标识符表，用于校验映射表。
- 边界：只提取数据，不复制 VS Code 源码。

### 1.3 piousdeer/vscode-adwaita — GPL-3.0-only

- 上游：<https://github.com/piousdeer/vscode-adwaita>（许可证：GPL-3.0-only）
- 关系：`src/tokens.py` 的 TextMate 作用域映射派生自该项目；`product-icons/`
  的产品图标字形（`scalable/*.svg` 与 `adwaita-icons.ttf`）复用自该项目，字形
  本身派生自 GNOME 的符号图标。`product-icons/symbolic/` 与
  `adwcode-symbols.ttf` 为本项目自有资产，使用 AGPL-3.0-or-later。
- 兼容性：GPL-3.0 §13 允许与 AGPL-3.0 组合作品，合并后的作品按
  AGPL-3.0-or-later 发布。

### 1.4 GNOME Builder 图标 — CC-BY-SA-3.0

- 上游：[GNOME/gnome-builder](https://github.com/GNOME/gnome-builder)，固定版本与
  原文件路径见 [来源记录](../product-icons/sources.json)。
- 许可依据是 `data/icons/COPYING`，不是项目代码的 GPL 许可。原始声明、
  CC BY-SA 3.0 Unported 全文及项目贡献者名单随附在 `product-icons/imported/builder/`。
- 关系：当前 25 个原始符号用于调试、版本控制、测试入口、补全与语言符号。
  `builder-symbols.ttf` 是经坐标、曲线和字重调整的单色字体，署名为 GNOME Builder
  contributors，改编由 AdwCode 完成（2026-10-05）。
- 边界：该字体与 SVG 保持 CC-BY-SA-3.0，作为独立艺术资产随附；不重新许可为
  AGPL，也不与 GPL 或自有字形合成一个字体。

### 1.5 MoreWaita — GPL-3.0-only

- 上游：[somepaulo/MoreWaita](https://github.com/somepaulo/MoreWaita)，署名为
  Paulo Fino 与 MoreWaita contributors；原始 `LICENSE` 与 `AUTHORS` 随附。
- 关系：保留包、开发工具和项目目录的 3 个备用符号，当前这些用途已优先采用
  Adwaita，MoreWaita 字体未参与运行时加载。原 SVG 位于
  `product-icons/imported/morewaita/`；转换为 `morewaita-symbols.ttf`（AdwCode，2026-10-05）。
- 边界：资产保留 GPL v3，原始 SVG、再生成脚本与来源记录一并提供；
  GPL-3.0 §13 允许与 AGPL-3.0 组合作品。

### 1.6 Adwaita Icon Theme — 选择 LGPL-3.0-only

- 上游：[GNOME/adwaita-icon-theme](https://github.com/GNOME/adwaita-icon-theme)，
  上游提供 LGPL v3 或 CC BY-SA 3.0 双重许可，本项目选择 LGPL 分支。
- 关系：37 个符号用于窗口、通用操作、终端、扩展、包和项目目录；署名为
  GNOME Project。转换后的 `adwaita-symbols.ttf` 保留 LGPL 许可（AdwCode，2026-10-05）。
- 原 SVG、许可声明、LGPL 与其引用的 GPL 全文位于
  `product-icons/imported/adwaita/`，再生成脚本与来源记录一并提供。

导入字体经字重校准后，`product-icons/rendered/` 中的 SVG 由其真实轮廓导出。
字体、导出轮廓与陈列缩略图沿用各来源许可，署名与字重参数见来源记录；
原始 SVG 及其哈希保持不变。

### 1.7 libadwaita 徽标 — LGPL-2.1-or-later

- 上游：`doc/libadwaita.svg`，署名为 The GNOME Project；固定版本与哈希见
  [来源记录](../assets/sources.json)。
- `assets/adwcode.svg` 直接采用原始徽标，字节与 `assets/upstream/libadwaita.svg`
  一致；`assets/adwcode.png` 仅由原始 SVG 等比导出，用作扩展图标。
- 原始 SVG 与上游 LGPL-2.1 许可全文随附于 `assets/upstream/`，资产保留上游
  LGPL-2.1-or-later 许可，不重新声明为本项目自有 AGPL 资产。
- 再生成方式见 [扩展图标说明](../assets/README.md)。
